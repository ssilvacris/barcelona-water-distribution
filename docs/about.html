About This Project

This project explores the distribution of public drinking fountains in Barcelona using open data from Open Data BCN (2019–2025). The analysis was performed using Python and published through an interactive map built with Leaflet.js and simple frontend technologies.

The dataset contains 1,736 fountains across the city's 10 districts. The web application allows users to explore this information dynamically, filter by district, locate the nearest fountain and understand spatial patterns of accessibility.

Full analysis, code and documentation are available in the GitHub repository and on Medium.
